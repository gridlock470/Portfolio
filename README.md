# Portfolio

> My personal developer portfolio – a hand-crafted static site built with pure HTML and CSS.

## 📖 Synopsis

Welcome to my personal portfolio repository. As a developer, I believe your portfolio should be as polished as your code – so I built this one from the ground up using **vanilla HTML5 and CSS3**, with no frameworks or libraries weighing it down.

This site is a visual introduction to who I am as a developer (Arjun Ahlawat), showcasing my projects, skills, and design philosophy. Every layout choice, hover effect, and color palette decision was made with intentionality – balancing aesthetic appeal with rock-solid performance and accessibility.

## ✨ Key Features

- **Pure HTML + CSS:** No JavaScript frameworks – just semantic markup and modern CSS.
- **Fully Responsive:** Built with CSS Grid, Flexbox, and media queries to adapt flawlessly from mobile to desktop.
- **Clean & Minimal Aesthetic:** Focused on readability and guiding visitors to my work.

## 🛠️ Built With

- **HTML5** – Semantic markup for accessibility and SEO.
- **CSS3** – Custom properties (variables), Flexbox, Grid, and transitions.
