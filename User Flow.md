# User Flow Diagram

## Simple Text-Based User Flow

### Main Navigation Paths

**Start:** User visits the portfolio

↓

**Home Section**
- View hero introduction
- See name and tagline

↓

**User chooses one of four paths:**

---

### Path 1: About Section
- Read biography
- View profile
- Download resume (optional)
- Return to Home or move to Projects

---

### Path 2: Projects Section
- Browse project cards
- Click on a project
- View project details
- Visit GitHub repository or Live Demo
- Return to portfolio

---

### Path 3: Skills Section
- View technical skills
- Explore tech stack
- Return to Home or move to Contact

---

### Path 4: Contact / Footer
- Connect on LinkedIn
- Visit LeetCode profile
- View GitHub profile
- Send email

---

### External Links (Open in new tab)
- LinkedIn
- LeetCode
- GitHub
- Email

---

### End Points
- Download Resume
- Return to Home
- Exit portfolio (via external links)

---

## User Flow Summary

```
Start
  ↓
Home
  ↓
  ├── About → Download Resume → End
  ├── Projects → Click Project → GitHub/Demo → Return
  ├── Skills → View Stack → Return
  └── Contact → Social Links → Exit
```

---

## Key User Journeys

| User Type | Path |
| :--- | :--- |
| General Visitor | Home → About → Projects → Skills → Contact |
| Recruiter | Home → About → Download Resume → LinkedIn |
| Developer/Peer | Home → Projects → Click Project → GitHub |
